# Definition of Done（完了定義）

## Phase 1: 着手前
- [ ] 対応する GitHub Issue で対象・対象外と検証可能な DoD を確認した。必要な判断は記録した。
- [ ] ほかの作業と衝突しないブランチ / worktree を用意した。

## Phase 2: 実装
- [ ] 対応する型レベル・ランタイム・統合テストを更新した。追加しない場合は理由を Issue に記録した。
- [ ] `code-comments.md` / `testing.md` の要件を満たし、必要な設計文書・README・Sphinx 本文と翻訳を更新した。

## Phase 3: コミット前
- [ ] `AGENTS.md` のビルド・テスト・lint / format の適切な範囲を実行し、失敗や未実行があれば明記した。
- [ ] 1 論理変更 1 コミットで、英語の動詞と絵文字で始めた。

## Phase 4: PR・マージ前
- [ ] Issue と PR をリンクし、DoD ごとの検証結果と未確認を記録した。未確認の項目を完了扱いにしない。
- [ ] セキュリティに関わる変更は権限・外部入力・漏洩をレビューした。
- [ ] main に直接 push していない。必要な CI と承認を確認してからマージする。

## Phase 5: マージ後
- [ ] GitHub で反映された SHA と Issue の状態を確認した。公開・実機稼働は別に検証する。
- [ ] 使用中・未コミット変更のある作業を保護し、対象 worktree だけ必要に応じて整理した。
