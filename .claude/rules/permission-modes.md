# Permission Mode 運用規約

Plan Mode は調査・検討に使い、判断・進捗の正本は GitHub Issue とする。小変更に長い計画書は不要。複数ファイルや不慣れな領域では、Issue の DoD と影響範囲を先に整理する。

モデル変更はツール権限を変えない。非対話実行や auto mode に切り替える場合も、既存の hooks・承認・作業範囲を維持する。信頼できないコードは現在の権限で実行せず、承認された隔離環境を使う。
