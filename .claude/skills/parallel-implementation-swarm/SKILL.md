description: 独立した Issue を別々の worktree に割り当て、個別の PR と検証で統合する。
---

## 実行手順

1. `.claude/rules/issue-workflow.md` に従い、目的が独立した Issue と所有者を確認する。共有ファイルが衝突する変更はコーディネーターが直列に扱う。
2. Issue ごとに作業範囲、変更してよいファイル、検証コマンドを渡し、専用 worktree を使う。ブランチ名は Issue 番号で区別する。既存の権限・承認を変更しない。
3. 各担当は Issue/PR URL、コミット、検証結果、残件を返す。コーディネーターは差分と衝突を確認し、統合後は対象間の回帰も検証する。マージは必要な承認後のみ。
