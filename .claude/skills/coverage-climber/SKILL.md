# Coverage Climber

対象は `.github/workflows/tests-coverage.yml` の matrix と同じ全パッケージ（`core`・`schema`・`plugin-*`）。パッケージごとに state と PR を分ける。

## 準備

- `.gitignore` に `.claude/coverage-progress.json` が無ければ追加する（個人の進捗なのでコミットしない）。
- state を読む。無ければ作る:
  ```json
  {"target_line_coverage": 85, "iteration": 0, "max_iterations": 200,
   "packages": {"@rescript-tauri/core": {"baseline": 72.5, "current": 72.5,
     "files_completed": [], "files_skipped": [{"path": "src/Mocks.res", "reason": "test-only module"}],
     "last_updated": "<ISO8601>"}}}
  ```

## ループ

1. **計測**: `pnpm --filter @rescript-tauri/<pkg> test:coverage` → `packages/<pkg>/coverage/coverage-summary.json`（`tools/vitest.shared.mjs` の json-summary reporter。計測対象は `src/**/*.res.mjs`）。
2. **候補**: line % が最も低いファイルを選ぶ（`files_completed` / `files_skipped` は除く）:
   ```bash
   jq -r 'to_entries | map(select(.key != "total")) | sort_by(.value.lines.pct) | .[0:5][] | "\(.value.lines.pct)\t\(.key)"' packages/<pkg>/coverage/coverage-summary.json
   ```
3. **テスト追加**: 対象の `.res` / `.resi` と既存の `tests/runtime/*.test.mjs` を読み、未到達の分岐を狙うテストを `tests/runtime/` に足して `pnpm --filter @rescript-tauri/<pkg> test`。
4. **失敗時**: テスト側を直して再実行（最大 5 回）。5 回失敗したら `files_skipped` に理由付きで記録して次へ。
5. **コミット**: green になったら 1 ファイル 1 コミット `✅ Add test cases for <module> (coverage <before>% → <after>%)`。
6. **state 更新**: `current`・`files_completed`・`iteration` を毎回書き込む（usage limit で中断しても次回そこから再開）。目標到達か `max_iterations` で停止し、人間のレビューを求める。
7. **PR**: 10 コミットごとに PR を作る（`main` へ直 push しない）:
   ```bash
   git push origin worktree-coverage-climb
   gh pr create --title "✅ Coverage climb: round N (xx% → yy%)" --body "Generated by coverage-climber skill."
   ```

## ガードレール

- **production code（`src/*.res` / `src/*.resi`）を変えてテストを通さない。**
- **assertion を緩めて通さない。** 意図が変わるなら skip する。
- `tests/`・`lib/`・`*.res.mjs`・`*.test.mjs` は対象外。`Mocks.res` は意図的に低カバレッジなので skip に登録。
